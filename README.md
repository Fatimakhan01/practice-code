# React Hooks Learning

This repository contains practice code created while learning and experimenting with React Hooks.

## 🔧 Technologies Used
- React.js
- JavaScript (ES6)
- Tailwind CSS (for basic styling)

## 📘 Hooks Covered
- useState
- useEffect
- useContext
- useReducer
- useCallback
- useMemo
- useRef

## 🎯 Purpose
The purpose of this repository is to understand React Hooks, state management, and component behavior in functional components.

## 📌 How to Run the Project
1. Clone the repository  
2. Run `npm install`  
3. Run `npm start`

## 📚 Status
Practice and learning repository.
